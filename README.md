# Cancer Gene Expression Analysis: PCA and K-Means Clustering

## Unsupervised Machine Learning | Dimensionality Reduction | TCGA RNA-Seq Data

This project explores how Principal Component Analysis (PCA) influences K-Means clustering performance on high-dimensional gene expression data from five cancer types.

The analysis covers data preprocessing, feature standardization, dimensionality reduction, clustering, and evaluation using Silhouette Score and Adjusted Rand Index (ARI).

## Project outline:

- Data cleaning and validation
- Data standardization
- Dimensionality reduction using PCA (Principal Component Analysis)
- K-means clustering
- Metrics discussion
- Conclusion

**Key finding**: Retaining more variance through additional PCA components does not necessarily improve cancer-type clustering performance.
